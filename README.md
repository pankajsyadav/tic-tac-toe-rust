# Tic Tac Toe in Rust

A simple command-line Tic Tac Toe game implemented in Rust.

## Features
- Two-player game
- Command-line interface
- Input validation
- Win/draw detection

## How to Play
1. Clone the repo
2. Run `cargo run`
3. Players alternate placing X and O
4. Enter row and column (0-2) to make a move

## Build
```bash
cargo build --release
```

## Run
```bash
cargo run
```
